# Armigo 学生基线与教师对照执行计划

**建议顺序：先做标准条件的 ACT 和 SmolVLA 闭环，再决定下一批数据该采什么。** 现有 248 条训练轨迹足以开始这个实验。实验分两次作决策：第一次看学生在哪个片段失效，第二次看恢复示范或教师信息是否在等预算下改变结果。以下为待执行计划，日期和依赖以 2026-11-20 的 `8a80b59` 为基准。已有证据、复现结果和源码定位见[审核报告](GEMINI_PROPOSAL_AUDIT_2026-11-20.md)。

## A. 冻结基线和评测口径

1. **建立运行清单。** 记录提交、数据清单和冻结评分参考的哈希、检测器、训练种子、增强、学生可见字段、动作块长度、控制频率、训练步数、batch、初始化权重、归一化、推理模式与结束阈值。每个模型和每组评测各用新目录。优先保留已有训练与验证集，所有新分支继承母轨迹的 split。[套件约定](../../config/vla/SUITES.md) · [原定门槛](../VLA_DISTILLATION_PLAN.md#L368)
2. **校验两条真实数据路径。** 随机从已导出轨迹选取片段起始、结束、重试和抓取帧。对同一帧比较 S9 加载器与 S10 客户端的三路图像裁剪、相机顺序、深度编码、36 维向量、上一动作和指令。验证段切换会清空动作队列。两组首轮都显式关闭训练增强；记录将来恢复光度增强时对应的新实验编号。
3. **冻结选模与算力预算。** 建议使用“完整验证集结束步 F1 ≥ 0.90 的候选中动作 MAE 最小”，并存最高 F1、最低 MAE 和末次模型的步数。若无人达标，可用预先指定的最高 F1 候选做诊断，结果标为 S9 未通过。正式报告须给终点正例数、提前/延迟、各片段和各关节的 MAE。评估 Smol 时固定推理噪声或重复估计，以免微小随机差值左右选模。维持同一模型进入所有主比较。
4. **用实际机器定工期。** 两种模型先各跑一次加载、预测、完整轨迹解码和短闭环，记录训练步速、加载峰值内存、验证用时、模型服务与仿真总耗时。Windows 多进程加载压力高时可从零 worker 起测。已有 Smol 短跑日志在步 10–60 约 1.127 秒/训练步；文档的 ACT 约 10 ms 是推理参考值。先测实际数据、模型与队列，再给首轮排期。[实测短跑日志](E:/scratch/bench/timed2.log) · [训练与模型说明](../VLA_DISTILLATION_PLAN.md#L258)

## B. 第一组可解释的学生闭环

**运行入口。** 以下是一套基线参数示例，供后续执行。以仓库根目录运行，输出使用新名字，固定 `--seed 42` 作为首个可复现锚点。正式步数按 A 阶段确定，两例中的 20,000 是仓库现行默认预算。示例将逐千步候选保存在各自目录；正式易读的结果表应指向按 A3 规则实际选中的候选，不能沿用现行 `best` 名称来替代选模。

```powershell
$trainRoot = 'E:/scratch/vla-pilot-train/lerobot'
$valRoot = 'E:/scratch/vla-pilot-val/lerobot'
$cudaPy = 'E:/il/lerobot-cuda/Scripts/python.exe'
& $cudaPy scripts/vla/train.py --family act --dataset $trainRoot --val-dataset $valRoot --no-augment --steps 20000 --seed 42 --out E:/scratch/s9-act-baseline-01
& $cudaPy scripts/vla/train.py --family smolvla --init-from lerobot/smolvla_base --dataset $trainRoot --val-dataset $valRoot --no-augment --steps 20000 --seed 42 --out E:/scratch/s9-smol-baseline-01
```

先让 ACT 跑通 S9、模型服务和一次 S10，再投入 SmolVLA。做全套离线验证时保留所有 52 条轨迹；截取前缀只用于冒烟。ACT 与 Smol 默认动作块长度为 100 和 50，执行方式分别为同步和异步。首表记录各自默认系统表现。若要归因给视觉语言预训练，则另做相同动作时域、相同执行接口、匹配预算或同骨干初始化的对照。

**评测入口。** 将下例的提示替换为 A3 选出的真实目录，两个模型各执行一次，分别给出新输出目录。已独立验证 Pilot 教师根目录能配对 60/60 个布局。

```powershell
$chosenCkpt = Read-Host '输入本次选中模型的完整目录'
$newEvalDir = Read-Host '输入该模型专用的新评测目录'
& .venv/Scripts/python.exe scripts/vla/eval_closed_loop.py --ckpt $chosenCkpt --suite config/vla/val.json --teacher-runs E:/scratch/vla-pilot-val --grader-ref E:/scratch/vla-pilot-grader_reference_frozen.json --mode auto --out $newEvalDir
```

| 必填结果 | 分母和解释 |
|---|---|
| 离线动作误差、结束步 F1（±2 帧） | 52 条导出轨迹。报告每类片段覆盖、正例数和按轨迹汇总的误差，同时保存原有按有效动作步汇总结果 |
| 成功分拣、误判、弃判、机械失败 | 60 个完整布局。额外报告 40 个缺陷布局的误判正常和弃判，以及 20 个正常布局的误报 |
| 配对差与区间 | 每个布局一行保存完整 case、教师/学生结果及四格计数，报告学生减教师的百分点差和按布局配对的 95% 区间 |
| 碰撞、片段失败和计算开销 | 全 60 次尝试均计入。记有接触的轨迹数和接触帧数，区分无记录与真零。按事件提取首次失败片段及原因，另列检测器误判、控制器弃判和未到达后继片段。记推理延迟、实际执行模式及每回合耗时 |

**推进规则。** 冻结教师参照为 57/60 时，0.7 倍门槛换算为学生至少 **40/60** 次成功，且全部 60 次均有可用碰撞记录、接触帧数为零。这个数字只用于该 Pilot。若只有离线 S9 过线，逐例检查目标关节、夹爪、抓取/释放、停止时刻和队列；若两模型都在同一处失败，优先检查共有控制器或数据接口。若成功率过线但出现碰撞，仍未通过。即使全过，也待 S12 指明数据方向后再决定是否扩到约 2,000 条。[原计划扩采条件](../VLA_DISTILLATION_PLAN.md#L400)

## C. 使恢复示范可学、使两类教师可比

1. **先修监督，再采扰动。** 在 `SegmentChunkDataset` 对每个未来目标检查片段、盲帧与接管边界；保守基线在第一个不可监督动作前截断，并用之前的最后一个有效动作填充。起点已盲时不贡献动作或终点损失；核验填充数据不会旁路进入有效监督。验收用审核报告的五帧反例，再加真实 S5 拼接 → LeRobot 导出 → 加载器 → 两种模型损失的测试。修改盲区里的动作哨兵后，有效目标及对应损失在固定随机量下应保持一致。
2. **分别验证四种扰动。** 对抓取前移动、夹爪内偏移、搬运中掉落、放下后轻推，在预先选定的训练布局运行分支。使用共同的父布局、干预强度和适用阶段，预定数量后记录全部尝试。分别计计划次数、实际触发、可观测变化、检测、开始恢复、最终成功与 S6 通过；核验检测在干预之后，盲帧区间和恢复首帧对应实际图像。将未进入触发阶段和已触发未恢复分列。沿用原 S5 要求：每类专家恢复率 ≥80%，每条导出分支有检测事件，至少一条通过 S0 回放。单例通路测试不足以估计恢复率。[现有集成测试](../../tests/test_vla_s5_perturb.py#L192) · [S5 门槛](../VLA_DISTILLATION_PLAN.md#L211)
3. **补评测注入和公平采集。** 为 S10 增加明确的学生扰动入口。成对运行无扰动与有扰动布局，用相同检测器、干预条件、幅度和评分；记录学生提前失败导致没有触发的比例。批采新增教师选项，并将学生深度噪声独立于教师模式。验收用同一物理状态、相同渲染/噪声种子，对比两种教师交给学生的相机数据与历史编码。固定控制器，切换教师时逐项列出哪些传感和恢复能力随之改变。
4. **预先规定纳入规则。** 评分、失败和类别分布继续留档。报告每组的尝试成本、S6 各项淘汰、各面/正常、重试和有效帧数。对 truth 下不适用的信念检查单独列出。主分析执行相同的安全与连续性要求，辅以共同合格布局子集的配对分析，并报告子集大小及其选择限制。只有稳定的反事实对照才能单独解释感知效应；若保留不同的恢复规则，就把结果称为两套教师系统的总效应。

## D. 等预算验证研究命题

**先测两位教师是否给出不同动作。** 在一组固定训练布局的相同物理状态和片段指令上，分别用两种教师可用的信号规划，统计同一下一步六个关节目标的差、结束决定是否一致，以及可配对状态的覆盖率。自由运行后的轨迹按片段或事件对齐，另报未配对路径。这样的检查能分辨“教师本来就很接近”与“教师有分歧但学生表现相近”，也能避免把时间错位当作动作差异。

**主表只设四组。** 先选一种可稳定运行的学生，用相同父布局池、优化更新数、batch、输入、执行模式和测试任务，比较下表。每组匹配可监督训练帧预算并记录独立父布局数、片段分布、重复前缀和实际采集成本。增加 S5 时以恢复帧替换部分干净帧，避免把多给的数据量算成恢复增益。

| 训练示范 | 普通轨迹 | 同预算加入可见扰动恢复 |
|---|---|---|
| truth 教师 | T0 | T1 |
| realistic 教师 | R0 | R1 |

分别报告 R0−T0、R1−T1、同一教师加入恢复后的变化，以及交互项 (R1−R0)−(T1−T0)。标准布局和预注册扰动组分开列出。建议主比较至少用 3 个独立训练种子，逐种子按相同布局配对，报告种子间分散度。不能把不同种子跑同一布局的结果当作独立布局扩大样本量。用于开发的 60 布局不提供独立确认；训练、筛选、阈值和最终配置冻结后，统一跑封存的 100 个标准测试布局。硬条件测试另设预先冻结的独立布局。

**机制消融逐项做。** 固定同一批数据，先比跨段动作块掩码；需要区分填充贡献时再单独改填充。对结束头使用正确对齐到旧指令的逐帧终止基线，匹配推理时延，统计早停、迟停和实际分拣。对盲帧和禁止回填分开比较；没有同状态专家标签的早期学生帧不能当作正确反事实标注。人为回填仅可作为明确标识的错误标签负对照。预算有限时优先选择 B 中最常见的失效机制，不要求一次性完成全矩阵。

**S11 独立测增量。** 仅在训练布局上接管，先以一个真学生完成触发 → 原地恢复 → S6 → 合并 → 微调 → val 的完整迭代。使用 Smol 前先修本地训练初始化并验证旧结束头、模型参数和归一化选择。核实实际新增的专家监督帧数；新增为零时记录该轮无有效新增。将“原模型仅继续训练相同步数”作为对照，比较新增接管数据的增量。当前接管专家使用 realistic 信号；四组都接入同一专家属于额外干预。报告触发率、拒绝率、有效帧、恢复率及全部碰撞。沿用连续两轮改善低于 2 个百分点的停止规则，并注明在 60 布局上每例约为 1.67 个百分点。

## E. 对三个扩展方向分别设立入口条件

| 扩展 | 最小实验 | 可以回答的问题 |
|---|---|---|
| 语言与自主决策 | 首先仅移除显式 bowl，保留片段时钟，保持图像/初始状态相同，成对交换指令中的合法目标碗，专测遵循指令；再移除片段 ID 或时间。当前 ACT 接口只取状态和图像，如要参加 language-only 比较须添加并验证文字编码，否则只能列为无语言基线。自主分拣则须同时去除文字中的目标碗、结构化 bowl 和控制器给出的决策，允许 UNKNOWN 并保留缺陷可见历史 | “能按语言放置”和“能自行看出缺陷并决定碗”可各自得到可解释的分数。多帧模型还要打通真实的历史输入，单改 `n_obs_steps` 不够。[ACT 输入](../../src/digital_twin_armigo/vla/models.py#L802) |
| 强部分可观测性 | 先在相同布局仅改变扰动，再分别做相机姿态、真实布局先验或物理参数。逐条件先验证两位教师的可达性、手眼标定、检测器基线和 S6 通过率。遮挡/杂物需要先具备教师可用的障碍感知；检查是否存在学生看得到、也确实能采取的恢复动作 | 可以区分信息不足、超出工作空间、检测器分布变化和物理域移。压力条件在看对照结果前确定；相同表现也是有效结果。[套件限制](../../config/vla/SUITES.md#L68) |
| Isaac、第二任务与 LLM | Isaac 先用同一轨迹对齐顶视 RGB、编码深度、腕视、内外参和动作前时刻，以带帧编号的已知运动测一帧滞后。按片段检验原 S13 门槛 RTX 动作误差 ≤1.5 倍 MuJoCo 误差，同时列绝对误差。通过后才评估 PhysX 闭环。若研究方向转向 agent 教师，可在一个需要新决策的任务上，让规则和真实 step-MCP LLM 使用相同工具、预算与布局，再蒸馏比较两者的学生 | S13 可检出渲染域问题；跨引擎闭环另测动力学和控制。LLM 的贡献以新增解决的失败、运行成本及最后的学生改善衡量。跨引擎和跨任务结论都需要各自的证据。[S13 定义](../VLA_DISTILLATION_PLAN.md#L349) · [Isaac 当前渲染入口](../../scripts/isaac/catalog_render.py#L140) |

首份实验报告只需要回答三个问题：选中的权重在 60 个布局中成功了多少次，失败首先发生在哪里，以及这些失败支持下一笔采集预算投向哪一种数据。其余扩展均由这三个答案决定。
