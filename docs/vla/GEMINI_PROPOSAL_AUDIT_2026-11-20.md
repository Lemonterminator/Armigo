# Gemini 蒸馏方案审核报告

**结论：有条件采纳。** 先用已有 Pilot 回答一个可以直接检验的问题：在控制器负责选视角、判断缺陷和指定目标碗的条件下，学生能否只靠约定的相机与状态输入，把专家的片段动作执行到足以完成分拣？这一结果决定是否值得投入教师对照、恢复采集和跨引擎实验。Gemini 对训练代码的两项诊断成立，第三项属于选模规则取舍。它低估了教师对照中的混杂，也漏掉了一个能实际复现的盲帧监督问题。[修订执行计划](GEMINI_PROPOSAL_PLAN_2026-11-20.md)

审核对象为用户提供的 Gemini 方案，基准为 2026-11-20 的本地 `main@8a80b59`。三位 Terra 子代理分别核查训练、闭环和论文。另直接读取了两套 Pilot 的合并元数据、全部数据行的三个监督标记、原始尝试清单和训练摘要，调用了当前教师配对读取函数，并用五帧内存样本验证数据加载行为。以下区分了实测、源码行为及待检验的假设。本次没有训练学生、运行全套测试或使用封存测试集评估策略。

## 3. 训练和评测中会改变结论的问题

### 首个基线

1. **确认顶视两路独立抽取裁剪。** 默认训练在 torch 路径逐相机采样，RGB 与深度的启用概率、裁剪区域及尺度独立。相同物体可能落到两路的不同像素。原文给出的 15–25 mm 没有逐样本投影或实测支撑，也没有测得闭环损失。首个控制组可用现成的 `--no-augment`。若以后保留增强，用同一对像素标记测量对齐误差，并区分关闭全部增强、仅保留光度变化、两路同步几何变化。固定相机下，共享裁剪也会改变绝对像素位置。深度的有效性通道应独立检验。[增强实现](../../src/digital_twin_armigo/vla/dataset.py#L94) · [训练默认值](../../scripts/vla/train.py#L375)
2. **确认 F1 优先，但尚无证据说明它已经选错模型。** 当前 `best` 先比结束步 F1，仅在差异不超过约 10⁻⁶ 时才比动作 MAE。最终摘要的 `s9_gate_pass` 指向末次验证。截取不打乱的验证集前几个 batch 还会遇到更严重的误读：若目标与预测均无片段终点，当前定义给 F1=1。正式比较须跑完整验证集，记录终点正例数、每段误差及最终选中的权重，再把该权重送入闭环。[训练验证与选优](../../scripts/vla/train.py#L293) · [F1 定义](../../src/digital_twin_armigo/vla/metrics.py#L94)
3. **S10 可以产生看似有效的错配分数。** 已有 episode 按输出目录中的编号复用，读取教师时按 seed 建表。部分 seed 匹配也能计算门槛，全体学生与教师子集的分母可能不同。每个权重使用新目录，要求完整 case、唯一对应和 60/60 覆盖，并检查配置。零碰撞指全部尝试的机器人/夹爪环境接触帧均为零且记录可用；缺陷漏检统计还包含未知，须单列“误判正常”和“弃判”。现有 S10 汇总不含 Gemini 所说的按 12 类片段闭环失败归因，需要从事件补表。[教师配对和门槛](../../scripts/vla/eval_closed_loop.py#L285) · [结果复用](../../scripts/vla/eval_closed_loop.py#L496)

### 引入 S5、S11 和两类教师之前

4. **实际复现跨盲帧监督。** 构造同段 5 帧，索引 2、3 为盲帧，动作第一维依次为 0–4，动作块长度为 4。用当前 `SegmentChunkDataset.from_episodes` 构造样本，索引 0 给出动作 `[0,1,2,3]`，掩码为 `[真,真,真,真]`；索引 2 自身才是全假。加载器只在起点检查盲标记，未来只截断片段边界和接管起点。这能把盲区动作送入更早预测的损失。应核验每个目标帧、填充及终点语义。当前 Pilot 的两列盲帧计数均为零，因此这一复现针对后续恢复实验。[加载器](../../src/digital_twin_armigo/vla/dataset.py#L532) · [盲区写入](../../src/digital_twin_armigo/agent/twin_record.py#L967)
5. **SmolVLA 本地微调会重新初始化结束头。** 项目权重包含 `policy.*` 和 `end_head.*`，Smol 的训练初始化路径仅加载前者，随后新建结束头。ACT 的本地初始化有完整加载路径。受影响的是从已有 Armigo 权重开始微调；首次加载上游基础模型时，新建项目专用头是预期行为。续训验收应使用实际入口，在零优化步、同输入、固定推理噪声时比较参数及预测；单独明确新旧归一化统计的选择。[Smol 加载](../../src/digital_twin_armigo/vla/models.py#L415) · [ACT 加载](../../scripts/vla/train.py#L138)
6. **两类教师会同时改变学生观看的深度和被筛选的样本。** 当前记录器只在 realistic 模式获得顶视 D415 噪声发生器。直接给批采脚本加 `--sensing truth`，truth 示范会带入不同的学生深度分布。S6 的信念误差在明确标记 truth 时直接通过，在 realistic 时逐视角检查阈值。导出器还要求单条连续、成功、无物理回滚的轨迹。因此“让学生模仿 truth 回滚”与现有导出规则冲突。应固定两组学生相机生成过程，并报告所有尝试、S6 各项和回滚淘汰率；若要估计感知信息本身的效应，还需匹配恢复方式。保留依靠原地重试得到的连续示范。[深度随机源](../../src/digital_twin_armigo/agent/twin_mujoco.py#L583) · [图像生成](../../src/digital_twin_armigo/agent/twin_record.py#L241) · [S6 信念评分](../../src/digital_twin_armigo/agent/vla_grader.py#L374) · [导出约束](../../src/digital_twin_armigo/agent/twin_record.py#L588)
7. **成功分拣与得到有效恢复标签是两个计数。** S5 分支记录器分别保存扰动、感知、恢复和最终结果，拼接条件 `sorted` 没有要求检测事件。S10 入口会统计已有扰动事件，但默认调用没有注入扰动。S11 迭代筛选 SUCCESS、eligible 和 S6 通过，可包含未接管的成功样本；即便这轮没有新增数据，仍可在既有数据上继续训练。没有逐类注入和有效监督计数，改善不能归因于恢复或接管。[分支统计及拼接](../../src/digital_twin_armigo/agent/perturbations.py#L533) · [S10 调用](../../scripts/vla/eval_closed_loop.py#L513) · [S11 迭代](../../scripts/vla/run_dagger_iter.py#L527)

## 4. 论文对标及可发表命题的边界

Agentic-Teacher 从一个已有学生的失败出发，让 coding agent 选择干预状态、开发并验证闭环代码策略，再用生成的续段和成功学生轨迹做后训练。Armigo 可借鉴的是“失败类型 → 针对性新增数据 → 学生是否改善”的证据链。使用 LangGraph、MCP 或让 LLM 在枚举动作中做选择，单独都不足以复现该贡献。[Agentic-Teacher 原文](https://arxiv.org/abs/2611.17394)

H2E 研究具身导航，通过原任务指令重标、路径监督和接近目标时的终止标注，让学生测试时无需查询 LLM。Armigo 的“结束当前抓取片段”和“整项质检已完成”对应不同的决策。两篇预印本可以支持对照设计，论文给出的数值不能作为本机械臂任务的基线。[H2E 原文](https://arxiv.org/abs/2611.16246v3)

近期研究问题可以写成：**在相同学生传感输入、相同数据和训练预算下，教师可用的额外信息以及带有可见原因的恢复示范，分别怎样改变新布局上的成功分拣率和碰撞率？** 保持标准环境并接受零差异。若只在某一种扰动上有改善，结论就限定在该扰动。单任务仿真、外部检测器和预定义片段仍是结论的适用范围。
