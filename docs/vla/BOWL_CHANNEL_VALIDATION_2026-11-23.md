# 目标碗独立通道 + 配对示范：验收协议（2026-11-24）

写于任何 T1 训练结果出来之前。实现计划见 [BOWL_CHANNEL_PAIRED_PLAN_2026-11-23.md](BOWL_CHANNEL_PAIRED_PLAN_2026-11-23.md)，问题定位见 [BOWL_SWAP_PROBE_2026-11-23.md](BOWL_SWAP_PROBE_2026-11-23.md)。

## 1. 背景

冻结的 fit30k 学生在 val2–val4 上做目标碗对照，237 个布局里跟随 0 例。bowl one-hot 能到达模型，但模型没有用它。这一轮做两项改动，并用全新布局 val5 验收：

- **碗通道**（`--bowl-token`）：one-hot 作为独立的编码器 token 输入，状态 token 里对应的三位清零。
- **配对示范**：在训练布局上，从同一个持砖检查点分出两支，一支按原目标放碗，一支放进另一只碗；两支都只监督搬运和释放帧。

## 4. 判据（运行前写定）

**主判据（验收）：**

- 用 `bowl_swap_probe.py` 和 `bowl_swap_report.py` 在 val5 上跑探针，方法与定义同 BOWL_SWAP_PROBE 第 2–3 节。
- T1 需同时满足：
  - 跟随率（跟随数 / 做了对照的布局数）≥ 85%；
  - `req` 与 `req2` 去向一致率 ≥ 90%。
- 基线也在 val5 上跑探针，作为同一布局集上的对照。预期接近 0，只作报告。

**次判据（决定是否把 T1 设为默认评测权重）：**

- 两组都用 `eval_closed_loop.py` 默认设置（等待夹稳 + 合拢退出 0.03，`--no-teacher`）在 val5 上各跑一次，按布局配对比较：
  - 最终分拣：T1 的点估计不低于基线；
  - 错碗：放置未确认且砖落进另一只碗的回合，T1 少于基线；
  - 首次夹稳：T1 比基线减少不超过 5；
  - 机械臂–环境碰撞：T1 没有新增布局（报告夹爪–环境接触，不设门槛）。
- 统计方法与 `clamp_wait_report.py` 相同：四格表、净差、bootstrap 95% 区间、精确 McNemar p。
- 两组权重不同，不共享 RGB 前缀，各自正常运行。

**判读：**

- 主判据满足、次判据也满足：`make_default`，T1 成为学生评测的默认权重。
- 只有主判据满足：`follow_ok_inspect`。碗通道起作用，但闭环有退化，逐例找出退化在哪一段。
- 主判据不满足：`not_accepted`。不调参复跑，按实现计划“若未达标”一节分流。

## 5. 已知偏离（相对实现计划，运行前记录）

1. **分叉点。** 计划写的是在 `present_bottom` 之后的持砖检查点分叉。但缺陷砖常常只靠腕部视角就判定，在 `place()` 里才抓取，不经过 `present_bottom`。所以 `TargetSwapTracer` 在 `place()` 开始搬运动作前、拿着砖时统一存检查点，并以它为分叉点。冒烟 4 对（2 正常、2 缺陷）都满足：分叉状态误差为 0，两支标签一致，目标相反，都通过导出检查。
2. **`--drop-unsupervised`。**
   - 配对回合只监督分叉后的搬运和释放帧，前缀以零损失样本的形式留在数据集里。按采集量估算约 70 万个，比原训练集的 39.5 万还多，会稀释 30k 步内的有效训练。
   - 因此新增了 `SegmentChunkDataset(drop_unsupervised=True)`，T1 训练时开启。
   - 这也会去掉 d_union 里 DAgger 回合接管前的零损失样本，所以 T1 在基础数据上的有效样本配比与 fit30k 略有不同。具体数量见第 6 节的数据记录。
3. **闭环统计脚本。** 计划没有指定脚本。新写的脚本只复用 `grasp_tail_report.load_arm` 等现有函数，统计第 4 节列出的量。
4. **配对回合只导出受监督部分。**（采集中途补记，仍在训练前）
   - 第一次全量采集把 E 盘写满，只成了 24 对。
   - 整段导出每条约 5 分钟，600 条串行要 40 小时以上。
   - 改为导出时从第一个受监督帧的前一帧开始（`--trim-unsupervised-prefix`，保留前一帧是为了让首个受监督帧的上一时刻状态仍在数据里），每批导出、读回校验后删除原始 mkv，6 个导出进程并行。
   - 被剪掉的前缀全是零损失样本，`--drop-unsupervised` 下本来就不进训练，归一化统计也只用受监督动作和保留样本，所以对训练等价。
   - 合并后的训练集放在 C 盘（E 盘放不下）。
